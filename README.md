# Sentiment-analysis
Improved customer satisfaction tracking by 20% through real-time feedback analysis for e-commerce platforms by developing
a sentiment analysis system using Bidirectional LSTMs and word embeddings, deploying the model on AWS.
• Achieved 85% accuracy in sentiment prediction by deploying a machine learning model using AWS EC2 and S3, integrating
it with a Flask web interface.
• Enhanced data visualization and business intelligence capabilities by implementing data analysis techniques, including
regression and forecasting, using Python, R, and SQL.
• Optimized ETL processes and data warehouse management for e-commerce sentiment analysis by utilizing SQL and AWS
technologies.
• Improved business analysis and root cause analysis efficiency through automation and statistical methods by applying machine
learning techniques and SAS
